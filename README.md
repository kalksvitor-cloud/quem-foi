# Quem Foi? Mistérios de lógica

Jogo de dedução em série: 5 temporadas, 50 casos, mapas de 4x4 a 12x12.
Cada linha e cada coluna tem exatamente uma pessoa. Use os depoimentos para descobrir onde cada um estava e quem foi o culpado.

Jogue em https://kalksvitor-cloud.github.io/quem-foi/ (funciona off-line e pode ser instalado na tela inicial).

O código-fonte do gerador e do modelo está em `fonte/`.
